## The claim — LINE OA MCP capabilities across 5 departments

Dr. Wasin's session organizes LINE OA MCP capabilities as a *"replace a whole team with a single operator + Claude Cowork / Claude Code / ChatGPT Work"* framework, one AI Agent per department:

### 1. Data Analyst
- Audience insights: friend counts, active/inactive users, message-quota consumption
- Broadcast performance: sent / opened / clicked
- Scheduled auto-dashboards
- Cost estimation when exceeding LINE OA package limits

### 2. Marketing
- Campaign research + planning
- Audience segmentation from LINE OA data
- Auto-scheduled broadcasts
- Flex Message journeys per Customer Journey stage
- Hot / Warm / Cold audience tracking + re-engagement

### 3. Creative
- Content + image prep for broadcast
- **Rich Menu creation via Claude directly — no LINE OA Manager UI needed**
- Image upload + menu layout via Claude
- Flex Message + Card Message bulk creation with auto-populated product images, promos, buttons
- **Render preview before broadcast**
- Claimed time reduction: **30 min → 3 min per creative task** (~10×)

### 4. Sales + CRM
- Lead behavior analysis from LINE OA conversations
- Customer + Lead database
- Coupon creation + management (LINE OA coupon system + LINE MyShop buttons)
- Payment-link generation + external social-channel distribution
- Sales tracking per campaign
- Full journey oversight from friend-add → purchase

### 5. IT + Operations
- System status + bug detection
- Connection debugging
- Chatbot + LINE API monitoring
- **Multi-account management** — many LINE MyShop stores, one operator
- Scheduled system automation (report digests, order tickets)

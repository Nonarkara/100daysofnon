# Input 54 — KitCost.net infographic: the *mobile-100%* website-building stack (6-step workflow, 7 tools)

**Source:** Thai-language infographic published at **kitcost.net** — *"KitCost ทำบนมือถือ 100% ใช้เครื่องมืออะไรบ้าง?"* ("KitCost — built 100% on mobile. What tools does it use?"). Subheader: *`</> Workflow + เครื่องมือที่ใช้ทำเว็บจริง </>`* ("Workflow + tools used to actually build the website"). The infographic walks through the exact toolchain the author used to build kitcost.net entirely on a phone.

## The verbatim 6-step workflow

| # | Step | Tool(s) | What happens |
|---|---|---|---|
| **1** | **มือถือ** (Mobile) | Notes app | คิดงาน · พิมพ์ prompt · ทดสอบจริง (Think · type prompts · test live) |
| **2** | **ChatGPT** | ChatGPT app | ช่วยวางแผน UX · คิดเนื้อหา · แตกงาน (Plan UX · draft content · break work into tasks) |
| **3** | **Claude / Claude Code** | Claude app + Claude Code | ทำโค้ด · แก้ UI · รัน test (Write code · fix UI · run tests). Specific outputs: Tasks/Tests · Tests pass · UI Responsive · Unit Tests · `npm test  / ✓ All tests passed` |
| **4** | **GitHub** | GitHub mobile | เก็บโปรเจกต์ · ดู diff · แยก branch (Store project · view diff · branch) |
| **5** | **Vercel + Browser** | Vercel app + mobile browser | Deploy เว็บ · เปิดดูจริง · ลองสด์ใช้งาน (Deploy · open live · try in real use). Screenshot shows kitcost.net live: *"Production Deployment / Ready / https://kitcost.net"* |
| **6** | **Screenshot + AI Image + Audit** | Screenshot tool + AI Image + SEO + Security audit + Tests | แคปหน้าเว็บ · ทำภาพ · ตรวจ SEO/Security (Capture page · make images · audit SEO/Security). Output: *"SEO Score 92/100 · Security Pass · Tests All Passed"* |

## Layer 2 — The embedded Prompt Formula

At the bottom of the infographic, a **universal 5-slot prompt scaffold:**

> **Role + Task + Context + Constraints + Output Format** (R-T-C-C-O)

This is the *most complete universal scaffold yet seen across Inputs 13, 16, 17* — it absorbs **RTF** (Role-Task-Format from Input 13) and **OAR** (Objective-Audience-Research from Input 16), then adds *Constraints* explicitly. Every other formula in Inputs 13 and 16 is a *specialization* of this universal scaffold for a specific class of task:

| Specialized formula | What it specializes |
|---|---|
| AIDA | Role=copywriter / Output Format=persuasive marketing copy |
| STAR | Role=interviewee / Output Format=behavioral-question response |
| PEEL | Role=academic writer / Output Format=paragraph-level essay structure |
| BAB | Role=narrative writer / Output Format=transformation story |
| SWOT | Role=strategic analyst / Output Format=4-quadrant matrix |

**Suggested Horizon canonization:** R-T-C-C-O is the **canonical** Horizon prompt scaffold (M1 baseline, taught first, used most often). The specialized formulas (PAR, AIDA, STAR, PEEL, etc.) are taught as *named templates* the learner can reach for when the task fits — but the universal scaffold is what the learner falls back to when no template fits, and what they understand the templates as *specializations of*.

This is a cleaner pedagogical sequence than presenting 20+ formulas as equals: **one canonical scaffold + a menu of specializations.**

## Layer 3 — The embedded Quick Tip + Self-check

**Quick Tip:** *"List 5 options"* + *"Ask clarifying questions first"* — two reusable meta-techniques that work across any formula.

- *List 5 options* is a generator-amplification trick — instead of asking AI for the answer, ask for 5 possible answers and choose. Reduces hallucination convergence, increases the learner's agency in the loop.
- *Ask clarifying questions first* is the same primitive as Input 10's brief-first / ask-back-first pattern, but phrased as a one-line instruction the learner adds to their own prompt: *"before you start, ask me 3 clarifying questions."*

Both belong in M1's prompt-primitives layer alongside the formulas, as **meta-techniques that compose with any formula**.

**Self-check (1 minute):**
1. Name 2 categories you use weekly
2. Pick 1 use case and write a 1-sentence prompt
3. Identify the output format you want

This is the **simplest possible diagnostic** for placing where a learner already is on the use-case grid. Three questions, sixty seconds, immediately actionable. It pairs with the Input 14 tier-ladder diagnostic — together they answer *what kind of work do you do, and how far up the AI-adoption ladder are you with that work?*
